# 测试复现与初审问题定位

## 一条命令复现

需要 MoonBit 工具链、Node.js 24；native 另需现代 C 编译器。
在仓库根目录执行，脚本失败立即停止，并打印实际失败命令：

```sh
node scripts/verify.mjs --target js
```

可将 js 换成 wasm、wasm-gc、native。每次执行包含工具链版本、格式检查、
check/build/test 和两个示例；JS 额外执行 17 项 CLI 检查及混合 JSONL 场景测试。
GitHub CI 使用同一脚本并覆盖四个目标，避免本地和 CI 步骤不一致。

## 请官方协助提供

失败的仓库提交 SHA、moon/moonc 版本、系统/目标后端、完整执行命令、第一处错误日志，
以及是否使用了额外测试或下载了其他版本的包。请勿在日志中包含 token 或密码。

README 的 JSONL 演示输入故意含一条坏记录，返回 1 是预期拒绝结果，不能当成全部
测试失败；但目前没有证据表明这是本次官方失败的原因。
